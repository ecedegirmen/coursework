## Topics

The [exercise folder](TypeScript%20Foundations%20Type/) contains practice with:

- Primitive and literal types, and type aliases
- `typeof` and `keyof`
- Index signatures and indexed types
- Mapped object types
- Generic type and function arguments
- Generic constraints and default arguments

The files are small exercise snippets, rather than a packaged application. Their original filenames and folder structure are preserved.
