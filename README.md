## How the materials are organized

Each course has an overview and resources page. COMP 290 groups actual files under assignments, lectures, practice, and final-project folders.

The original repositories and their histories remain intact. The [source inventory](SOURCE-INVENTORY.md) records the original path and Git blob SHA for every copied file. Copies are snapshots, not automatic synchronization.

Research projects remain in the separate [research portfolio](https://github.com/ecedegirmen/research-portfolio). Original course prompts and scaffolding are retained; third-party resources are linked rather than copied.
